🛒 E-Commerce Sales Dashboard | Power BI

📌 Project Overview

This project is an interactive E-Commerce Sales Dashboard developed using Microsoft Power BI. It provides insights into sales, profit, quantity sold, customer purchases, and payment methods through visualizations and KPI cards.

🎯 Project Objectives

- Analyze overall sales and profit.
- Identify top-performing states and customers.
- Understand product category and sub-category performance.
- Track monthly profit trends.
- Analyze payment method preferences.
- Support data-driven business decisions.

🛠️ Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- CSV Dataset

📂 Project Files

File Name| Description
"Details.csv"| Sales details dataset
"Orders.csv"| Order information dataset
"Ecommerce_Dashboard.pbix"| Power BI dashboard file
"Ecommerce_Dashboard.png"| Dashboard screenshot

📊 Dashboard Features

- KPI Cards: Average Order Value (AOV), Total Quantity, Total Sales Amount, and Total Profit.
- Sales by State: Analyzes sales across states.
- Quantity by Category: Compares quantities sold by product category.
- Monthly Profit Trend: Displays monthly profit performance.
- Top Customers by Sales: Identifies customers contributing the most sales.
- Sales by Payment Mode: Compares payment methods.
- Profit by Sub-Category: Examines profit across product sub-categories.
- Quarter Slicer: Filters dashboard data by quarter.

🚀 How to Run the Project

1. Download or clone this repository.
2. Open "Ecommerce_Dashboard.pbix" in Power BI Desktop.
3. If prompted, connect the data source to "Details.csv" and "Orders.csv".
4. Refresh the data if required.
5. Use the slicers and charts to explore sales performance.
